# Добавление имущества

## Сайт

Страница добавления нового имущества в систему учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Добавление имущества»;
- форма с полями: название, инвентарный номер, категория;
- кнопка «Добавить имущество»;
- кнопка «Отмена»;
- карточка «После добавления» с информацией о статусе и ответственном.

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Добавление имущества».
2. `test_form_has_required_fields` - форма содержит поля с id: assetName (название), inventoryNumber (инвентарный номер), category (категория).
3. `test_submit_button_exists` - на форме есть кнопка type="submit" с текстом «Добавить имущество».
