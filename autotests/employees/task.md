# Сотрудники

## Сайт

Страница со списком сотрудников системы учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Сотрудники»;
- форма поиска по ФИО и фильтр по подразделению;
- таблица с 3 сотрудниками: Иванов, Петров, Сидоров;
- кнопка «+ Добавить сотрудника».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Сотрудники».
2. `test_three_employees_displayed` - в таблице отображается 3 записи сотрудников.
3. `test_add_employee_button_exists` - на странице есть кнопка с текстом «Добавить сотрудника».
