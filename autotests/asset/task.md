# Карточка имущества

## Сайт

Страница карточки конкретного имущества системы учёта материальных ценностей «Подотчёт». Отображает детальную информацию об имуществе Lenovo ThinkPad T14 (INV-0001).

На странице отображаются:
- название и инвентарный номер имущества;
- основная информация: категория, дата поступления, состояние, статус;
- история операций с датой, типом операции, сотрудником и комментарием;
- карточка «Текущий ответственный» с информацией о закреплении;
- карточка «Действия» с кнопками: «Изменить», «Оформить выдачу», «Списать имущество».

## Что проверить

1. `test_asset_title_displayed` - на странице отображается заголовок h1 с названием «Lenovo ThinkPad T14».
2. `test_inventory_number_displayed` - на странице отображается инвентарный номер «INV-0001».
3. `test_history_has_three_records` - в таблице истории операций отображается 3 записи.
4. `test_responsible_section_exists` - на странице есть карточка с заголовком «Текущий ответственный».
5. `test_action_buttons_present` - в карточке «Действия» есть 3 кнопки, включая кнопку «Оформить выдачу».
