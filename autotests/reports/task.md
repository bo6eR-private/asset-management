# Отчёты

## Сайт

Страница формирования отчётов системы учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Отчёты»;
- карточка «Параметры отчёта» с полями: тип отчёта, с даты, по дату, кнопка «Сформировать»;
- секция «Доступные отчёты» с 4 карточками: по имуществу, по сотрудникам, по выдачам, по возвратам;
- секция «Экспорт» с кнопками «Экспорт в PDF» и «Экспорт в Excel».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Отчёты».
2. `test_four_report_cards_exist` - на странице есть 4 карточки с заголовками: «Отчёт по имуществу», «Отчёт по сотрудникам», «Отчёт по выдачам», «Отчёт по возвратам».
3. `test_export_section_exists` - на странице есть секция «Экспорт» с кнопками «Экспорт в PDF» и «Экспорт в Excel».
