# Оформление выдачи

## Сайт

Страница оформления выдачи материальной ценности сотруднику в системе учёта «Подотчёт».

На странице есть:
- заголовок «Оформление выдачи»;
- форма с полями: Сотрудник, Материальная ценность, Дата выдачи, Планируемая дата возврата, Подробное состояние, Комментарий;
- кнопка «Оформить выдачу»;
- кнопка «Отмена».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Оформление выдачи».
2. `test_submit_button_exists` - на странице есть кнопка с текстом «Оформить выдачу».
3. `test_cancel_button_exists` - на странице есть кнопка с текстом «Отмена».
