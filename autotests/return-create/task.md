# Оформление возврата

## Сайт

Страница оформления возврата материальной ценности от сотрудника в системе учёта «Подотчёт».

На странице есть:
- заголовок «Оформление возврата»;
- форма с полями: Сотрудник, Материальная ценность, Дата возврата, Состояние при возврате, Комментарий;
- кнопка «Оформить возврат»;
- кнопка «Отмена».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Оформление возврата».
2. `test_submit_button_exists` - на странице есть кнопка с текстом «Оформить возврат».
3. `test_cancel_button_exists` - на странице есть кнопка с текстом «Отмена».
