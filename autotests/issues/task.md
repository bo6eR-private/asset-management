# Выдачи имущества

## Сайт

Страница с историей выдач системы учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Выдачи имущества»;
- форма фильтрации по сотруднику, статусу и датам;
- таблица с 3 записями выдач: Dell UltraSharp, HP ProBook, Logitech MX Keys;
- кнопка «+ Оформить выдачу».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Выдачи имущества».
2. `test_three_issues_displayed` - в таблице отображается 3 записи выдач.
3. `test_create_issue_button_exists` - на странице есть кнопка с текстом «Оформить выдачу».
