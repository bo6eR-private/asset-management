# Изменение имущества

## Сайт

Страница редактирования информации об имуществе в системе учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Изменение имущества»;
- форма с предзаполненными полями: название, инвентарный номер (readonly), категория;
- кнопка «Сохранить изменения»;
- кнопка «Отмена»;
- карточка «Текущий ответственный»;
- карточка «Информация» с подсказкой.

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Изменение имущества».
2. `test_inventory_number_is_readonly` - поле с id="inventoryNumber" имеет атрибут readonly.
3. `test_responsible_section_exists` - на странице есть карточка с заголовком «Текущий ответственный».
