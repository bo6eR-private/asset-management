# Учёт материальных ценностей

## Сайт

Система учёта материальных ценностей «Подотчёт»: страница со списком имущества, поиском и фильтрацией. Все данные хранятся прямо в странице, фильтрация происходит на клиенте без перезагрузки.

- в системе 3 единицы имущества: Lenovo ThinkPad T14 (INV-0001), Dell UltraSharp (INV-0002), Офисное кресло (INV-0003);
- у каждой единицы есть: инвентарный номер, название, категория, состояние и статус;
- на странице есть форма поиска по названию или инвентарному номеру;
- на странице есть фильтры по категории (Компьютерная техника, Мебель, Оборудование) и статусу (На складе, Выдано, На ремонте, Списано);
- результаты отображаются в таблице с колонками: Инв. номер, Название, Категория, Состояние, Статус, кнопка «Открыть»;
- при отсутствии результатов отображается сообщение «Имущество не найдено».

## Что проверить

1. `test_assets_list_displays_all_items` - на странице отображается список имущества с инвентарным номером, названием, категорией, состоянием и статусом.
2. `test_search_by_name` - поиск по названию работает корректно (например, «Lenovo ThinkPad T14»).
3. `test_search_by_inventory_number` - поиск по инвентарному номеру работает корректно (например, «INV-0001»).
4. `test_search_nonexistent_asset` - при поиске несуществующего имущества отображается сообщение «Имущество не найдено».
5. `test_filter_by_category` - фильтрация по категории работает корректно (например, «Компьютерная техника»).
6. `test_filter_by_status` - фильтрация по статусу работает корректно (например, «На складе»).
7. `test_open_asset_card` - в каждой строке таблицы есть кнопка «Открыть».
