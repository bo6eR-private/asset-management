# Добавление сотрудника

## Сайт

Страница добавления нового сотрудника в систему учёта материальных ценностей «Подотчёт».

На странице есть:
- заголовок «Добавление сотрудника»;
- форма с полями: ФИО, Должность, Подразделение, Телефон, Email;
- кнопка «Добавить сотрудника»;
- кнопка «Отмена».

## Что проверить

1. `test_page_title_is_correct` - на странице отображается заголовок h1 с текстом «Добавление сотрудника».
2. `test_submit_button_exists` - на странице есть кнопка с текстом «Добавить сотрудника».
3. `test_cancel_button_exists` - на странице есть кнопка с текстом «Отмена».
